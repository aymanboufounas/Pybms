# The 100-function reference

Generated by `python tools/generate_docs.py`. Import once with `import pybms as pb`.
Use `pb.function_help('name')` for the same signature, explanation and example in Python.

Table examples use `df = pb.classification_data(rows=100, features=4)` unless a specific schema is shown.
Names such as `price`, `city`, `date`, `id` refer to columns in your own dataset.
`X`/`y` are numeric features/targets, `result` is a TrainingResult, and `network` is a native Model.

Established numerical methods come from NumPy, pandas, scikit-learn and Matplotlib.
Pybms supplies the convenience API, validation, orchestration and native dense training implementation.


### `train`

```python
train(data, target='target', *, task='auto', estimator='linear', test_size=0.2, trials=4, cv=3, seed=42, scoring=None, param_grid=None)
```

Train a pipeline with a held-out test set and CV hyperparameter search.

data is a table with target column, or pass train(X, y). estimator is linear,
forest, extra_trees, sgd, or auto. trials limits configurations per estimator.
cv limits folds. Default classification scoring is balanced_accuracy;
regression uses negative RMSE (larger is better). Imputation/encoding/scaling
fit within each fold. Independent rows are required; grouped/time-series
datasets need an explicit evaluation strategy outside this convenience API.

```python
result = pb.train(df, target='target')
```
