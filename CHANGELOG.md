# Changelog

## 0.2.0

- Added 100 documented functions across datasets, cleaning, arrays, plots, training, optimization, syntax and help.
- Added local files, direct URL loading, offline sample datasets, seeded synthetic data, and optional Excel/Parquet readers.
- Added tabular training pipelines with training-only cross-validation, bounded parameter search, and held-out evaluation.
- Added generic SGD/Adam gradient descent, numerical gradients and analytical gradient checks.
- Extended native dense models with reproducible seeds, validation loss, early stopping, gradient clipping, string labels and array/JSON model persistence.
- Corrected multi-output loss gradient normalization and compile-before-inference loss selection.
- Added function/method/keyword typo assistance, conservative source repair, CLI help and IDE re-exports.
- Added examples, API reference, exceptions guide, bibliography, tests, wheel/sdist packaging, CI and Trusted Publisher workflow.

## 0.1.0

- Initial NumPy dense neural-network prototype with activations, losses, SGD/Adam, summaries and typo-friendly methods.
